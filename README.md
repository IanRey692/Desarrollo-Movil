## 🧭 Cómo navegar este repositorio

- Cada carpeta (`P1`, `P2`, ...) es **autocontenida**: incluye su propio código fuente, instrucciones de ejecución y documentación.
- No es necesario ejecutar nada desde la raíz del repositorio; entra a la carpeta de la práctica que te interese y sigue su `README.md`.
